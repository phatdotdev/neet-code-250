## 📖 Overview

The **NeetCode 250** list is a carefully selected roadmap of coding challenges covering core algorithmic patterns (such as Two Pointers, Sliding Window, Binary Search, Trees, Dynamic Programming, and Graphs). 

This repository tracks my journey in solving these problems, focusing on:
- Optimal time & space complexity ($O(N)$, $O(1)$, etc.).
- Intuitive explanations and pattern recognition.
- Clean and readable code.
